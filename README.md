# 🚀 Satyajit Portfolio Website

A modern and responsive personal portfolio website built using **Next.js, React, and Tailwind CSS** to showcase my skills, projects, and achievements.

---

## 📸 Preview

![Portfolio Preview](./public/Satyajit.jpg)

---

## 🛠️ Tech Stack

- ⚛️ React.js  
- ⚡ Next.js  
- 🎨 Tailwind CSS  
- 💻 JavaScript  
- 🌐 HTML5 & CSS3  

---

## ✨ Features

- 🔥 Modern UI with smooth animations  
- 📱 Fully responsive design  
- 🧑‍💻 About, Skills, Projects, Achievements sections  
- 📄 Resume download option  
- 🎯 Interactive components (Cursor Trail, Particle Background)
